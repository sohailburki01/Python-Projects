## Projects

### Calculator
A simple, interactive command-line calculator. 
**Learning Objectives:** Using basic math operations, loops, conditional statements, and functions.
**Features:** 
* Perform Addition, Subtraction, Multiplication, Division.
* Option to add exponents and nth root calculate

### Guessing Number Game
A playful "guess the number" game with twist and betting mechanics!
**Learning Objectives:** Random number generation `random` module, while loops, input validation, scoring mechanisms.
**Features:** 
* Easy and Hard difficulty levels.
* Allows user to bet desired amounts of money.

### HangMan
The classic Hangman word-guessing game.
**Learning Objectives:** Strings/Lists manipulation, keeping track of attempts, loop controls.
**Features:** 
* Hidden word guessing with 6 attempts before losing.

### Password Generator
A security utility to create random passwords.
**Learning Objectives:** String manipulation, importing modules, conditions.
**Features:** 
* Choose password strength level: Weak, Medium, or Strong.

### Rock Paper Scissors
The classic hand game played against the computer.
**Learning Objectives:** Game logic loops, input evaluation, win/loss counters.
**Features:** 
* Best of 5 series (first to win 3 rounds wins the match).
* Follows standard game rules (Rock beats Scissors, Scissors beats Paper, Paper beats Rock).

## Installation & Requirements

These projects are built with standard Python. No external dependencies or complicated installations are required.

1. Install [Python](https://www.python.org/downloads/) (Version 3.x is recommended).
2. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/rajveer-0402/Python-Projects.git
   ```
3. Navigate into the freshly cloned repository:
   ```bash
   cd Python-Projects
   ```

## How to Run

1. Open your terminal/command prompt.
2. Navigate to the project directory you want to run. For example, to run the Calculator:
   ```bash
   cd Calculator
   ```
3. Run the Python `main.py` script:
   ```bash
   python main.py
   ```
   *(Note: Depending on your system configuration, use `python3` instead of `python`)*
