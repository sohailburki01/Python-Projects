# 🧮 Calculator

A simple command-line calculator built in Python to test my learning.

## ✨ Features

- Addition, subtraction, multiplication, and division
- Exponents (powers)
- Nth root
- Easy to run, with no extra libraries needed

## 📋 Requirements

- Python 3.x

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/deepashreen02-dev/Python-Projects.git
   ```
2. Go into the Calculator folder:
   ```bash
   cd Python-Projects/Calculator
   ```
3. Run the program:
   ```bash
   python main.py
   ```

## 💡 Example

```
Enter first number: 8
Enter operator: ^
Enter second number: 2
Result: 64
```
